# B 组交付说明：当前实现状态

## 1. 现状说明

仓库现已按**单板方案**整理，`esp_outdoor/` 已删除，不再作为主工程保留。
当前 `firmware/` 顶层已经补出单板入口文件，用于统一后续结构收敛。

## 2. 当前保留内容

- `main/`：单板主流程入口（当前从 `esp_indoor` 主线整理而来）。
- `components/`：公共组件，如网络、事件日志、ESP-DL 探针。
- `models/`：模型资源目录。
- `tools/`：模型转换、数据集和辅助脚本。
- `vision/`：视觉推理资料与 POC 文档。

## 3. 当前真实状态

- 单板主叙事已经统一。
- 文档主线已不再以 `esp_outdoor` 作为项目能力来源。
- 但代码层面仍有一部分旧的 `indoor/outdoor` 命名和 topic 设计，后续还需要继续收敛。

## 4. 后续建议

建议下一步继续处理：

- 把 `esp_indoor/` 的组件逐步上收或重命名为单板模块。
- 把公共协议里的 `indoor/outdoor` topic 改为 `device/*`。
- 清理视觉资料里仅用于双板历史记录的说明。

# LabGuard 单板项目介绍

## 一、项目概述

`LabGuard SingleP4` 是一套面向实验室现场部署的安全监测固件。仓库当前只保留已经接上线的硬件链路：摄像头、环境传感器、执行器、音频和网络通信。

- 摄像头链路负责采集画面并输出预览帧。
- 传感器链路负责温湿度、VOC、MQ-2 数据采集。
- 执行器链路负责风扇、水泵、声光输出。
- 音频链路负责从 SD 卡播放 WAV 告警音。
- 网络链路负责 Wi‑Fi 与 MQTT 通信。

## 二、当前边界

当前项目**不再包含**：

- 演示型 PPE / 火焰 / 烟雾识别。
- mock 场景切换。
- `force_*`、`selftest` 这类演示命令。
- 双板协同叙事。
- 视觉推理 POC 和导出脚本。

## 三、系统架构

### 1. 设备链路

- `camera_capture/`：SC2336 + CSI + ISP + EK79007 这条硬件链路。
- `sensor_reader/`：SHT3x / ENS160 / MQ-2 这条硬件链路。
- `actuator_ctrl/`：风扇、水泵 GPIO/PWM 控制。
- `audio_prompt/`：SD 卡 WAV + MAX98357A I2S 播放。

### 2. 通信链路

- `labguard_net/`：Wi‑Fi / MQTT。
- `event_log/`：事件记录。
- `labguard_common/`：统一数据结构与 topic 编解码。

## 四、软件设计

### 1. 目录

```text
firmware/
├─ CMakeLists.txt
├─ main/
├─ components/
│  ├─ labguard_common/
│  ├─ labguard_net/
│  ├─ event_log/
│  ├─ sensor_reader/
│  ├─ camera_capture/
│  ├─ actuator_ctrl/
│  └─ audio_prompt/
└─ models/
```

### 2. 主流程

1. 初始化网络、传感器、摄像头、执行器和音频。
2. 读取传感器数据并发布 MQTT 状态。
3. 读取摄像头帧并发布预览帧。
4. 按风险状态驱动风扇、水泵和告警音。

## 五、说明

当前仓库已经被收敛为“硬件接线优先”的版本。若未来要重新加入视觉推理，需要单独恢复一个明确的模型推理模块，而不是混在演示代码里。
